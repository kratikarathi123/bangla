# Contributing to Bangla Language Model Evaluation

We welcome contributions to improve this evaluation framework! Here's how you can contribute:

## 🚀 Ways to Contribute

### 1. Adding New Models
- Add new language models to the evaluation framework
- Update the model list in `model_evaluator.py`
- Test the new models and submit results

### 2. Improving Evaluation Metrics
- Implement additional metrics (BLEU, ROUGE, etc.)
- Add category-specific evaluation
- Enhance the evaluation methodology

### 3. Dataset Improvements
- Add support for new dataset formats
- Improve data loading efficiency
- Add data validation and quality checks

### 4. Performance Optimization
- Optimize GPU memory usage
- Improve batch processing
- Speed up evaluation pipeline

## 📋 Submission Guidelines

### Pull Request Process
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Add tests if applicable
5. Update documentation
6. Commit your changes (`git commit -m 'Add amazing feature'`)
7. Push to the branch (`git push origin feature/amazing-feature`)
8. Open a Pull Request

### Code Standards
- Follow PEP 8 style guidelines
- Add docstrings to functions and classes
- Include type hints where appropriate
- Add comments for complex logic

### Testing
- Test your changes on a small dataset first
- Ensure GPU compatibility
- Verify that existing functionality still works

## 🐛 Bug Reports

When reporting bugs, please include:
- Python version
- GPU specifications
- Error messages and stack traces
- Steps to reproduce
- Dataset information (if relevant)

## 💡 Feature Requests

For feature requests, please provide:
- Clear description of the feature
- Use cases and benefits
- Implementation suggestions (if any)

## 📝 Documentation

Help us improve documentation by:
- Fixing typos and grammar
- Adding examples
- Improving clarity
- Translating to other languages

## 🤝 Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help others learn and grow
- Follow GitHub's community guidelines

## 🎯 Current Priorities

1. **Model Support**: Adding more Bangla-specific models
2. **Evaluation Metrics**: Implementing semantic similarity metrics
3. **Performance**: Optimizing for different GPU configurations
4. **Documentation**: Adding more usage examples

## 📞 Contact

- Open an issue for bugs or feature requests
- Start a discussion for general questions
- Contact maintainers for sensitive issues
